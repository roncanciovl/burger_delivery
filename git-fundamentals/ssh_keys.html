🔐 SSH Keys

Acceso seguro y sin contraseñas a repositorios privados en GitHub usando criptografía de llave pública.

1. ¿Por qué SSH?

Los repositorios de los equipos son privados. Si intentas clonar por HTTPS sin un token, GitHub bloqueará la acción (Permission denied). SSH permite identificar tu computadora de forma segura sin pedir contraseñas todo el tiempo.
