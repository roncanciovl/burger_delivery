GitHub vs Bitbucket & Ecosistema Atlassian

Comprende la estructura de Workspaces, la organización por Proyectos y Repositorios en Bitbucket y cómo se conecta todo con Jira, Confluence y GitHub.

🔷
Atlassian
Ecosistema Empresarial de Software

Atlassian es la empresa matriz creadora de la suite más utilizada en el desarrollo corporativo y metodologías ágiles (Scrum/Kanban).

  • ✓ Jira: Gestión de tickets, sprints, épicas y bugs.
  • ✓ Confluence: Documentación viva y wikis técnicas.
  • ✓ Bitbucket: Alojamiento Git y CI/CD Pipelines.
  • ✓ Trello: Tableros ágiles visuales y ligeros.
🪣
Bitbucket
Git Repo Host de Atlassian

Servicio de repositorios Git en la nube diseñado para integrarse de forma nativa e invisible con Jira y Confluence.

  • ✓ Workspaces: Contenedor raíz para equipos/empresas.
  • ✓ Proyectos: Agrupación lógica de repositorios.
  • ✓ Bitbucket Pipelines: CI/CD integrado por YAML.
  • ✓ Smart Commits: Control de Jira desde Git.
🐙
GitHub
Microsoft Ecosystem

La plataforma de desarrollo colaborativo más grande del mundo, hogar de casi todo el código Open Source global.

  • ✓ Organizations: Agrupación de usuarios y repos.
  • ✓ GitHub Actions: El motor de CI/CD más popular.
  • ✓ GitHub Issues & Projects: Seguimiento integrado.
  • ✓ Comunidad Global: Forks, Stars, Sponsorships.
🌐 Mapa de Relación del Ecosistema
💡
¿Por qué las empresas usan Bitbucket con Jira? Si un desarrollador nombra su rama feature/NAV-42-arm-controller o incluye NAV-42 en el mensaje del commit, Jira actualiza automáticamente la columna del ticket a "En Desarrollo", muestra los PRs abiertos, el resultado de los tests de Pipelines y los reviewers asignados sin que nadie tenga que actualizar Jira manualmente.

🔍 Comparativa Visual Directa: ¿Cómo difieren en estructura?
🐙

GitHub: Modelo Plano (2 Niveles)

Organization ➔ Repositorios

En GitHub, los repositorios viven todos en una lista plana directamente bajo la Organización o Usuario:

🏢 Organization: github.com/robotics-corp
├── 📦 burger_delivery
├── 📦 kinova_arm_driver
├── 📦 fleet_api_server
└── 📦 web_dashboard
⚠️ Si tienes 200 repositorios, todos están en la misma lista sin agrupación por producto.
🪣

Bitbucket: Modelo Agrupado (3 Niveles)

Workspace ➔ Proyectos ➔ Repositorios

En Bitbucket, los Proyectos agrupan repositorios relacionados y les aplican permisos compartidos:

🏢 Workspace: @robotics-fleet
├── 📁 Project: AUTONOMY (AUT)
│ ├── 📦 burger_delivery
│ └── 📦 kinova_arm_driver
└── 📁 Project: FLEET-CLOUD (FLT)
├── 📦 fleet_api_server
└── 📦 web_dashboard
✨ Configuras Branch Protection una sola vez en el Proyecto y cubre todos sus repositorios.
🌐 ¿Tu cuenta puede tener múltiples Workspaces? ¡Sí!

Una sola cuenta de Bitbucket (tu Atlassian Account) puede crear y ser miembro de múltiples Workspaces a la vez (por ejemplo: tu Workspace personal gratuito para experimentos, el Workspace corporativo de tu empresa y el Workspace de un cliente o universidad).

📋 Ver y administrar todos tus Workspaces

Puedes ver la lista completa de Workspaces a los que perteneces, tu rol en cada uno (Admin/Member) o crear uno nuevo desde la consola central:

🔗 bitbucket.org/account/workspaces/ ↗
🔗 ¿Por qué la URL es bitbucket.org/<workspace>/<repo>?

En la URL de Git (bitbucket.org/workspace/repo.git), el Workspace es la raíz directa. El Proyecto actúa como un contenedor lógico de permisos dentro de Bitbucket; esto permite mover repositorios entre proyectos sin alterar los remotos de Git de los desarrolladores.

⚡ Smart Commits: Controlar Jira desde tu Terminal Git

Cuando trabajas con Bitbucket y Jira, puedes manipular tickets de Jira directamente en el mensaje de commit de Git usando sintaxis de Smart Commits: 

$ git commit -m "BGR-45 #comment Implementado nodo de cinemática inversa #time 2h 30m #resolve"
BGR-45
Clave del ticket en Jira. Vincula el commit, la rama y el PR directamente a la vista de Jira.
#comment <texto>
Publica un comentario automático dentro del ticket en Jira con el texto indicado.
#time 2h 30m
Registra horas trabajadas (Worklog) en Jira para contabilidad y seguimiento del sprint.
#resolve / #close
Transiciona el estado del ticket a "Resuelto", "Cerrado" o la columna final configurada.

⚖️ Comparativa Exhaustiva: GitHub vs Bitbucket
Característica 🐙 GitHub 🪣 Bitbucket
Enfoque Principal Open Source, proyectos personales y empresas globales. Empresas, entornos corporativos y equipos ágiles con Jira.
Estructura Organizacional Organization ➔ Repository Workspace ➔ Project ➔ Repository
Gestión de Tareas / Issues GitHub Issues & GitHub Projects (sencillo, markdown puro). Integración profunda con Jira Software y tableros Scrum.
Motor de CI / CD GitHub Actions (enorme marketplace de workflows). Bitbucket Pipelines (configurado en bitbucket-pipelines.yml).
Protección de Ramas Branch Protection Rules por Repositorio (o Rulesets de Org). Branch Permissions heredables a nivel de Proyecto y Repo.
Autenticación Remota Personal Access Tokens (PAT) o Llaves SSH. App Passwords con permisos granulares o Llaves SSH.
Comunidad & Descubrimiento Máxima visibilidad (Stars, Forks, Trending, Discussions). Privado por defecto, orientado a trabajo interno de empresas.
🔐 Permisos y Roles en Bitbucket Workspaces
👑 Workspace Admin

Control total del Workspace: facturación, planes, invitar miembros, crear/eliminar Proyectos y Repositorios, configurar llaves SSH de despliegue y OAuth consumers.

📁 Project Admin / Write

Permiso concedido a un grupo sobre un Proyecto entero. Todos los repos dentro del proyecto heredan automáticamente acceso de lectura, escritura o administración.

📦 Repo Write (Developer)

Permite clonar, crear ramas, hacer push a ramas de feature, abrir Pull Requests y correr pipelines. El push a ramas principales (main) puede estar bloqueado por Branch Permissions.
