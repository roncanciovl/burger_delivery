¿Qué es un Workspace?
VS Code vs Bitbucket vs ROS 2

La misma palabra, tres mundos completamente diferentes. Descubre la diferencia entre un Folder y un Workspace en VS Code, una Organización en Bitbucket y un entorno de compilación en ROS 2.

🪟 En VS Code: ¿Es "Workspace" lo mismo que "Folder"?

No son lo mismo. Aunque en el uso diario muchas personas los confunden, en Visual Studio Code existen dos modos de trabajo bien definidos:

📁

1. Folder (Carpeta simple)

Single-folder workspace implícito

Ocurre cuando abres un solo directorio (File > Open Folder... o ejecutando code .).

  • El explorador solo muestra lo que hay dentro de esa carpeta raíz.
  • La configuración local se almacena en la subcarpeta .vscode/settings.json.
  • No permite mezclar proyectos que viven en distintas partes de tu disco duro.
🪟

2. Multi-root Workspace (.code-workspace)

Espacio multi-carpeta explícito

Ocurre cuando guardas un archivo nombre.code-workspace (File > Save Workspace As...).

  • Permite tener múltiples carpetas independientes abiertas juntas en el mismo explorador.
  • Ideal si trabajas en el paquete ROS 2, la API en FastAPI y la documentación en una sola ventana.
  • Define extensiones recomendadas, tareas (tasks.json) y depuradores comunes.

🏢 En Bitbucket: El Workspace es tu Organización en la Nube

      

        A diferencia de VS Code, en Bitbucket un Workspace no es un archivo de tu computadora. Es una cuenta/organización remota en los servidores de Atlassian.
      


      

        

          
🏢 Responsabilidades del Workspace en Bitbucket

          
    
            
  • Facturación y Plan: Define si la empresa usa plan Free, Standard o Premium.
    • 
            
  • Gestión de Usuarios: Grupos como @developers, @robotics-qa.
    • 
            
  • Espacio de Nombres de URL: Define la URL de Git (bitbucket.org/nombre-workspace/repo.git).
    • 
            
  • Proyectos y Repos: Agrupa proyectos como AUTONOMY o CLOUD.
    • 
          

        


        

          
🌐 ¿Tu cuenta puede tener varios Workspaces?

          

            ¡Sí! Tu cuenta personal de Atlassian puede pertenecer a tu Workspace personal (gratuito) y al de tu empresa simultáneamente.
          

          
            🔗 bitbucket.org/account/workspaces/ ↗
          
        

      


      
      

        
      

    

  


  
  
  
  

    

      
🤖 En ROS 2: El Workspace es tu Entorno de Compilación (`ros2_ws`)

      

        En robótica con ROS 2, un Workspace es un directorio físico en tu sistema operativo Linux estructurado de manera específica para que la herramienta colcon pueda compilar múltiples paquetes de nodos en C++ o Python.
      


      
      

        

          
1. src/ (Source)

          

            Aquí clonas o creas tus paquetes (burger_delivery). Es el único directorio donde editas código manualmente.
          

        


        

          
2. build/ (Build)

          

            Creado automáticamente por colcon build. Almacena objetos compilados y llamadas a CMake/setuptools.
          

        


        

          
3. install/ (Install)

          

            Contiene los ejecutables listos para correr y el script vital source install/setup.bash.
          

        


        

          
4. log/ (Logs)

          

            Guarda el registro de errores y advertencias de cada invocación de compilación de colcon.
          

        

      


      

        
🚀

        

          Ciclo de vida en el ROS 2 Workspace:
          
cd ~/ros2_ws
colcon build --symlink-install
source install/setup.bash
ros2 run burger_delivery delivery_navigator

        

      

    

  


  
  
  
  

    

      
⚔️ La Gran Comparativa: ¿Cuál Workspace es Cuál?

      
      

        

          
            

              Criterio
              🪟 VS Code Workspace
              🏢 Bitbucket Workspace
              🤖 ROS 2 Workspace
            

          
          
            

              ¿Dónde reside?
              Local en tu PC (archivo .code-workspace).
              En la Nube (servidores Atlassian Cloud).
              Local en tu disco Linux (~/ros2_ws).
            

            

              ¿Qué contiene?
              Rutas a carpetas abiertas + configuraciones de extensiones y depuración del IDE.
              Facturación, usuarios, grupos de permisos, proyectos y repositorios Git.
              Código fuente en src/ y binarios compilados en install/.
            

            

              ¿Quién lo procesa?
              El editor de código (Visual Studio Code).
              El servidor web de Bitbucket y Pipelines de CI/CD.
              El compilador colcon y el middleware de ROS 2.
            

            

              ¿Cómo se crea?
              File > Save Workspace As...
              Desde la web en bitbucket.org/account/workspaces/
              mkdir -p ~/ros2_ws/src
