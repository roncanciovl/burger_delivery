👥 Usuarios & Roles en GitHub

Un repositorio puede tener múltiples tipos de participantes, cada uno con distintos permisos. Selecciona un rol para ver sus capacidades.

Permisos detallados — 👑 Owner

👑 Owner — Dueño del repositorio

El Owner es quien creó el repositorio (o una organización). Tiene control total: puede hacer push, merge, cambiar configuraciones, agregar collaborators, cambiar visibilidad (público/privado) y hasta eliminar el repo.
