🔄 Local vs Remoto

Entiende las áreas de trabajo de Git: Working Directory, Staging Area, Local Repo y Remote Repo.

1. Working Directory (Directorio de Trabajo)

Aquí es donde editas tus archivos. Los archivos modificados aparecen como cambios locales (Untracked o Modified). Git los nota pero aún no están preparados para un commit.
