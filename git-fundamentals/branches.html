🌿 Git Branches

Las ramas permiten que cada integrante del equipo desarrolle módulos en paralelo sin alterar la rama principal main.

📌 Estado inicial — rama main

La rama main contiene la versión base del proyecto. En la metodología del curso, main está protegida por Rulesets: nadie hace push directo a ella.

🏢 Convención de Ramas para Trabajo en Equipo

Usa la estructura estándar: feat/estudiante-apellido-modulo (ej. feat/carlos-gomez-monitor).
